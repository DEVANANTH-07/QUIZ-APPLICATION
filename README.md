# Quiz Application 

A simple Java console-based Quiz Application developed using Core Java concepts like loops, conditions, and user input handling. This project allows users to answer multiple-choice questions, calculates scores automatically, and displays performance-based results interactively.

## Features

- Multiple choice quiz system
- Interactive console based interface
- Score calculation
- Result evaluation system
- Uses loops and conditional statements
- Beginner friendly Java project

## Technologies Used

- Java
- Scanner Class
- Loops (`for`)
- Conditional Statements (`if-else`)
- Console Input/Output
